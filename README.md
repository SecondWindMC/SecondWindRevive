# SecondWind — DBNO revive plugin for Paper 1.21.x

Players survive lethal damage in a downed state (crawl + bleed-out); teammates revive by sneak-holding nearby, enemies can execute.

**Download:** see [Releases](../../releases) — or on [Hangar](https://hangar.papermc.io/SecondWindMC/SecondWindRevive).
**Buy / support:** https://secondwindmc.github.io — $5.99
**Docs:** drop the jar in `plugins/`, restart, edit `plugins/SecondWind/config.yml`.
